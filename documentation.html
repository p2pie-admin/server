Модуль server

Этот модуль представляет собой Fastify-приложение из монорепозитория p2pie, которое отдаёт статический интерфейс, публикует JSON-API по данным обменников и направлениям обмена, а также проксирует создание отзывов в headless CMS (Strapi) после AI-модерации. Источником оперативных данных служит Redis, поверх которого построен собственный слой кэша в памяти.

Назначение модуля

  • поднять HTTP-сервер Fastify с логгером и статиками из каталога public/;
  • зарегистрировать все маршруты из src/routes (через registerGeneralRoutes) и эндпоинт создания отзывов;
  • прочитать бизнес-данные из Redis, нормализовать их (helpers) и отдавать внешним клиентам;
  • принимать отзывы пользователей, дополнять их IP-адресом, проверять количество дублей, пропускать через runModeration, а затем вызывать GraphQL-мутацию Strapi;
  • предоставлять вспомогательные отчёты (статистика воркеров, ошибки, список городов, популярные направления, крипто-курсы и т.д.).

Ключевые функции и утилиты

registerGeneralRoutes(server) (src/routes/registrator.ts)
Итерирует список файлов в src/routes/* и подключает обработчики GET-эндпоинтов (города, курсы, статистика, справочники).
registerCreateReviewRoute(server) (src/routes/createReview/index.ts)
Регистрирует POST/OPTIONS /createReview, собирает валидированное тело (buildReviewInput), добавляет IP (attachIpAddress), проверяет лимиты (hasTooManyReviews), запускает AI-модерацию и вызывает callStrapi(CreateReviewMutation).
getCitySelector(dir?) (src/routes/citySelector/utils.ts)
Читает города и «грязные» курсы из Redis, передаёт их в convertCitiesToSelector и кэширует результат через toCache, чтобы строить «селектор города» по конкретному направлению или по всем сразу.
convertCitiesToSelector(...), getDirRatesMin(), extractOrderedRateIds(), getCleanDirRates() (src/helper.ts)
Помогают нормализовать курсы и отфильтровать их по весам стран/городов, дополнить параметрами обменников и отсортировать выдачу.
toCache({ key, ttl, getData }) (src/helper.ts)
Лёгкий in-memory кэш поверх Map, который снижает нагрузку на Redis/Strapi и переиспользуется практически во всех маршрутах.
initializeRedis, setObject, setData, getObject, getData, getKeys, getFirstObjectEntry (src/redis.ts)
Инициализируют соединение с Redis, предоставляют универсальные функции чтения/записи коллекций, неблокирующее перечисление ключей и аккуратное завершение работы.
mylog(), sleep(), waitSec() (src/helper.ts)
Утилитарные функции логирования и таймингов, которые используются во время фоновых операций (парсинг, модерация и т.п.).

Поведение по умолчанию

  • Все ответы, кроме главной страницы, возвращаются в формате JSON и снабжены заголовком Access-Control-Allow-Origin: *.
  • Часто запрашиваемые ресурсы проходят через toCache, а данные origin'а хранятся в Redis (ключи вида allDirtyRates, exchangers, stats и т.д.).
  • При завершении процесса сервер аккуратно закрывает соединение с Redis, дождавшись завершения всех операций.
